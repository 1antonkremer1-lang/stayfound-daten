# StayFound Daten

Fertige Dateien mit Adressen, Straßen und Orten (Apotheke, WC, Spielplatz ...) ganzer Länder und Bundesländer für die App StayFound.
Die App lädt sie von hier, damit Adresssuche, Navigator und die Orte auf der Karte ohne Internet funktionieren.

- Die Dateien liegen unter [Releases, Marke `gebietsdateien`](../../releases/tag/gebietsdateien), die Liste in `index.json`.
- Erzeugt werden sie mit dem Werkzeug in `tools/gebietsdateien` über den Workflow "Gebietsdateien erzeugen" (von Hand starten, Regionen angeben; `deutschland` steht für alle 16 Bundesländer einzeln).
